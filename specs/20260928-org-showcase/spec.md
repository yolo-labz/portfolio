# Organization showcase presentation

## Scope
Improve only the existing homepage open-source shelf. Leave featured case studies,
personal positioning, the project catalogue, deployment and repository policy intact.

## Hypothesis
The undifferentiated ten-row shelf makes it difficult to choose a starting project
or distinguish a project explanation from its source repository.

## Acceptance
- Offer four explicit starting points covering messaging, infrastructure, speech
  and system tooling; preserve access to every other existing catalogue item.
- Each selected project has an existing localized description, technology labels,
  a clearly named project link and a separate source link.
- Identify yolo-labz without asserting uptime, popularity, new metrics or brand approval.
- Work at 320px and desktop widths, with readable contrast, visible keyboard focus,
  an operable disclosure and reduced-motion support.
- Render EN/PT/ES on mobile and desktop; retain visual baselines without relaxing tolerances.
- Use existing typography, colors and components. No dependencies or placeholder art.
- Consume p9 imagery only if successful output, provenance and permitted usage are
  all supplied; exploration is not an approved brand master. Missing art does not
  block a text-first layout proposal.
- No production merge/deploy, workflow changes, other-seat edits or vault writes.
